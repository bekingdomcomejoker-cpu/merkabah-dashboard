- Spirit vector routing
- Harmony Ridge resonance
- Truth-Love integration metrics
- System health and performance
- Operation history and logs

## Installation

```bash
chmod +x scripts/install_dashboard.sh
./scripts/install_dashboard.sh
```

## Usage

```bash
# Launch dashboard
dashboard

# Show specific face
dashboard face MAN

# Export data
dashboard export json

# Show metrics
dashboard metrics

# View history
dashboard history 50
```

## Data Extraction

The dashboard can extract and export:
- Operation history (JSON, CSV)
- Performance metrics
- Harmony Ridge data
- Face statistics
- Vector routing logs
- System health reports

## Keyboard Controls

| Key | Action |
|-----|--------|
| `q` | Quit |
| `f` | Toggle faces view |
| `h` | Show harmony ridge |
| `m` | Show metrics |
| `e` | Export data |
| `r` | Refresh |
| `↑/↓` | Scroll history |
